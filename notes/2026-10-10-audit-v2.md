## What this audit fixed (all shipped the same day)

- **P1 — Font payload.** Garamond Math (536 KB) preloaded on every route → off
  the critical path (`preload:false`; loads where math renders). Root EB
  Garamond split: Regular+Italic preload, Medium+Bold load on first use; the
  split was first attempted with a composite family stack and reverted when
  the matching rules proved it produces faux-bold (a browser matches the first
  family and synthesizes within it) — final form is hand-rolled `@font-face`
  with React-hoisted preloads. Chair's secondary faces (Plex Mono, Source
  Serif, Anton) and manufacture's Anton off the preload path. All seven root
  faces + the atlas's two converted TTF→woff2 with TTF fallback:
  **3,863 KB → 1,340 KB of font source**.
- **P1 — A11y labels.** Essay sliders (time/body/bond intensity), the wheel
  scrub, the desire input, the atlas search — labeled. `lang="en"` on the
  atlas. sr-only `h1` on all eight OHCOSE phase hubs; the manufacture cold
  open's duplicate `h1` became `h2`.
- **P1 — Overflow (geometry).** The landing year spine collided (fixed by
  redesign to a flow chronology); OHCOSE's intake header overflowed 69px at
  390 (wrapping field groups); the chair schematic badge 21px (wraps ≤700px).

## Correction log

- **2026-10-10 — the atlas boot failure (my error, reported by Adnan).** The
  JetBrains Mono vendoring inserted a quoted family name into double-quoted
  HTML style attributes and single-quoted JS strings; fixing one context with
  single quotes broke the other (the second context had been fine). The
  dc-runtime's logic class failed to evaluate and the atlas rendered
  props-only from the font-vendoring deploy until now. Fixed by using the
  unquoted multi-word family form (`font-family: JetBrains Mono, …`), which
  is valid in CSS declarations, JS string literals of either quoting, and
  HTML attributes alike. Rule derived: when injecting a named font into
  mixed-quoting contexts, use the unquoted family form; verify interactive
  pages with a console capture, not only the detector and geometry.
