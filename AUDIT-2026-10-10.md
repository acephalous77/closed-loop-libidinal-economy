# autostimulus.org — audit and streamlining plan

*2026-10-10 · commissioned by Adnan ("audited, streamlined, and ready for
editing") · measured on this Mac against HEAD `1e19319`, working tree clean.*

**How this was measured.** `npm run build` → green, 274 static pages.
`npm run lint` → 63 problems (1 error, 62 warnings). Eight read-only audits
(each work + shell + cross-artifact truth check), with prerendered output in
`.next/server/app` checked directly for emitted tags. The lint report used
throughout: `/tmp/autostimulus-lint.txt`.

**The one-sentence state.** The site builds and mostly works, but it is
running two full versions of closed-loop, publishes false statements about
its own privacy behavior, tells Google that 18 pages *are* the homepage, and
carries ~90 MB of unoptimized or dead assets — all fixable without touching a
single deliberate design decision.

## 1. Cross-cutting findings (severity-ordered)

### C1. Wrong canonical on 18 indexable pages — **worst live defect**
Root layout (`app/layout.tsx:100`) pins `alternates.canonical: "/"`, and any
page that doesn't override inherits it. Verified in prerendered HTML:

- `/closed-loop/instrumentation`, `/closed-loop/colophon`
- all 14 `/closed-loop/the-dynamics/*` v1 plates
- `/manufacture-of-the-subject`
- `/ouroboric-condition`

Each emits `<link rel="canonical" href="https://www.autostimulus.org">` —
i.e. "I am a duplicate of the homepage." Google may drop all 18 from the
index. (Preview routes and `/thinkroom` carry it too but are noindexed and
being removed/noindexed anyway.)

**Fix:** remove the root-level canonical; set explicit self-canonicals on the
landing page and every route currently inheriting (mechanical, per file).

### C2. Instrumentation disclosure is no longer true
`content/instrumentation.mdx` says: "There are no cookies. No local storage,
no session storage… The site is fully static and the same for every reader."
Verified false at site level:

- `/thinkroom` sets a cookie (`tr_pass`, httpOnly, 30 days) and is gated
  dynamic (proxy.ts).
- localStorage/sessionStorage keys in four works: `ouroboric-atlas-v5`
  (ouroboric), `pss-born` (manufacture),
  `chair-zine-fitting-notif-shown` (chair), `atlas_intro_seen`
  (psychopolitics).
- `/psychopolitics-atlas` unconditionally loads React, ReactDOM (and lazily
  Babel) from `unpkg.com` — a third-party origin, contradicting both this
  page and `next.config.ts`'s comment ("no route loads script from a
  third-party origin").

**Fix:** vendor React locally (the same UMD builds already sit in
`public/simulator/vendor/`), recompress og.png, add `lang` + canonical; and
rewrite the disclosure page to be true and precisely scoped (that rewrite is
Adnan's page — draft + his ruling).

### C3. closed-loop runs two full versions, half-orphaned, both indexed
- `/closed-loop` hub presents **v2 only** (`v2-argument`, `the-apparatus`,
  `v2-dynamics` — `components/home/FrameworkOrientation.tsx`). No link to v1.
- v1 (27 routes: the 5 essays + note via MDX, mathematics, 14 dynamics
  plates, reading-list, open-questions, colophon, instrumentation) is
  reachable only by accident: two v2 footers, one chair link, sitemap.
- The 5 v1 essays are **unique content** (v2-argument is a different,
  condensed surface). The 14 v1 plates overlap 8 v2 plates. `the-mathematics`
  vs `the-apparatus` overlap heavily. Colophon duplicated
  (`/closed-loop/colophon` vs `/closed-loop/the-colophon`).
- Sitemap publishes both branches; `/closed-loop/instrumentation` has **zero
  clickable inbound links anywhere**; `public/llms.txt` still advertises v1
  as the canonical reading order.

**Fix: Adnan's ruling needed** (see §4, Q1). Mechanism is ready either way.

### C4. Sitemap omits 24 chair routes; stale priority branches prove it was accidental
`app/sitemap.ts` `CHAIR_ROUTES` lists only `/chair` + `/chair/colophon`,
while the priority function below it references `/chair/essay`, `/chair/zine`
etc. Missing: essay, zine, concepts, refusal, subsystems (+7), lineage (+6),
precedents (+4). (`/chair/archive` + children are deliberately noindexed and
correctly absent.)

### C5. Docs and machine surfaces are materially stale
- `README.md`: works table has 4 of 7 works; three statuses wrong ("in
  production" for fully built works); "Future projects will add their own
  subdirectories" — they exist.
- `public/llms.txt`: OHCOSE "three phases / 21 sub-protocols / IV–VII
  forthcoming" (reality: 8 phases / 46 sub-protocols, all live); v1 reading
  order; "eight open questions" vs three in §8 / ten on the page; missing
  Manufacture; conflicting years (chair 2021 vs 2025; ouroboric 2018 vs 2026;
  OHCOSE 2025 vs 2026).
- `app/patriotic-times/layout.tsx:28,42`: "35 plates" — the book is 63.
- Landing JSON-LD (`app/page.tsx:197`): "Six live projects" vs 7 works;
  psychopolitics missing from both descriptions; `sameAs: []`.
- License over-broad: README + landing footer say site text is CC BY-SA;
  Patriotic Times is CC BY-NC-SA.
- `public/chair/ils/README.md` served publicly; describes routes as they
  were before the redesign; says images use `<img>` when they use next/image.

### C6. OG/metadata hygiene beyond C1
- Every child route of chair / ohcose / patriotic, and every v2 closed-loop
  route, inherits the parent's `og:url` (e.g. all 63 plate pages say
  `og:url=/patriotic-times`; every chair page says `/chair`).
- Works with **no OG image at all** (inherits generic atelier card and its
  own layout's image-less object): ohcose, patriotic-times, chair,
  manufacture. 37 closed-loop routes + ouroboric have proper cards
  (`lib/og-card.tsx` reused 37×).
- Doubled title suffix on 16 v1 pages ("colophon — The Closed-Loop Libidinal
  Economy — The Closed-Loop Libidinal Economy").

### C7. Asset weight — ~90 MB, mostly unearned
- `public/patriotic-times`: 63 PNGs, 52.9 MB; the plates index renders all 63
  as raw `<img>` full-size, no lazy, no dimensions → one visit ≈ 53 MB.
- `public/chair`: 50 MB, of which **41 MB in `ils/`** — four unused source
  PNGs (`Image 1–4.png`, 7–10 MB each, referenced nowhere; 35 MB), plus live
  images at 0.7–1.7 MB each.
- `public/psychopolitics-atlas`: og.png 181 KB (recompressable);
  atlas-data.js 362 KB (108 KB gz — acceptable).
- Unused template SVGs at `public/` root (next/vercel/globe/window/file).

### C8. Lint: 63 problems — 1 error, 62 warnings
- **Error (only in repo):** `app/ouroboric-condition/_components/Atlas.tsx:128`
  — `<a href="/">` should be `Link` (its sibling link is already `Link`).
- Real bugs hiding among warnings:
  - `SomaticOptimization.tsx` — `Math.random()` during SSR render →
    **hydration mismatch on every load** of that v1 plate.
  - `Schematic.tsx` — nested component defined in render; hover/focus
    remounts SVG groups → **keyboard focus is dropped**; also two
    `router.push` targets 404
    (`section-0/0.3-axioms`, `section-0/0.2-closure` should be
    `section-0#axioms`, `#closure`).
  - `PatrioticTimes ColoringCanvas` — refs read during render → CLS on
    non-3:2 plates; `ReclamationTrajectories`/`CapturedResonance` (v1) —
    refs-during-render + draw-before-declare (concurrency risk).
- Benign-but-noisy: ~15 `set-state-in-effect` (mostly deliberate mount
  gates), unused vars, etc.

### C9. Accessibility items worth fixing (not urgent, but cheap)
- 31 range sliders across the v2 plates + v1 `InterventionPanel` lack
  labels (label text is a sibling div).
- Math tooltips (the glossary popovers on MDX pages) are hover/click-only —
  not keyboard-openable.
- `.term` glosses on manufacture are hover-only (the pedagogical core).
- ColoringCanvas has no keyboard path (WCAG 2.1.1); palette buttons ~38 px.
- Heading-level skips in chair essay/concepts/colophon; five dead buttons on
  /chair (focusable, no handler).
- `globals.css`: `--space-sm/--space-md` undefined (silently zero);
  `summary`/`[role=button]` excluded from the focus-visible rule.

### C10. Dead code / orphans ready for removal
- `app/v2/depth-layers` + `app/v2/schematic` — noindexed previews whose own
  docstrings say "will be removed before v2 ships"; v2 has shipped; both
  have canonical users elsewhere.
- `app/chair/_components/OuroborosPortal.tsx` (1,615 lines) + its only
  importers `PhaseDiagrams.tsx` + `Effects.tsx` (2,445 lines total) — zero
  importers repo-wide; six artifact images they alone reference.
- Unused exports: `Marginalia`, `MarkerCircle`, `RedactionBar`,
  `PolaroidCard`, `BROCHURE` tokens, `useReducedMotion`.
- Stale glossary flags ("§8.4 not yet built") while §8/§12/§3.5 pages exist.
- `the-colophon` still says v2 lives on branch `v2/closed-loop-rebuild`
  (merged long ago).
- Chair `ils/README.md` publicly served (see C5).

## 2. Per-work state and streamlining list

### The Closed-Loop Libidinal Economy (2026) — the largest
v1: 27 routes, 10 MDX files (essays/mathematics/reading-list/open-questions —
the clean editing seam), 14 interactive plates (inline prose + client SVG/Canvas
components), no MDX frontmatter, works. v2: 38 routes — v2-argument (curated
8-move prose), the-apparatus (§0–§12, 15 formal results, DepthLayers kit),
v2-dynamics (12 plates on a new sim engine), the-architecture (schematic),
the-instruments, glossary (26 terms), the-colophon, 18 apparatus detail pages.
No placeholders except stale "not yet built" flags. The simulator
(`public/simulator`, React vendored locally, compiled 2026-07-31) is linked
from the v1 dynamics hub only.

Streamline: C1/C3/C6 fixes; delete previews (C10); fix Schematic 404s + focus
loss; fix SomaticOptimization hydration; label 31 sliders; stale glossary
flags; math-tooltip keyboard; unify world-nav duplication. **The essays are
the editorial crown — keep them exactly as they are; the streamlining here is
plumbing.**

### OHCOSE (2025)
56 routes (hub, colophon, 8 phase hubs, 46 leaves). Verified: zero broken
links, zero orphans, prev/next chain contiguous, all 46 leaves declare their
dossier, all statically rendered (no hydration risk). The structure is the
most disciplined on the site. Issues: all prose inline TSX (~7,800 lines in
leaves, ~1,200–1,500 lines being repeated chrome); Phase I's 6 leaves predate
the shared SectionHead (typography drift, local copies); one stale draft
footer on `cradle-anchoring`; dead draft-branch code in Phase I hub; no OG
card; seal.png 236 KB served (rendered at 320 px); 3 unused vars.

Streamline: a manifest module (phases/leaves/prev-next) consumed by all
surfaces — kills every sync hazard; a LeafShell scaffold driven by it;
migrate Phase I to shared SectionHead; OG card; seal optimization; lint
zero-out. **Editing surface after: each leaf's prose block stands alone.**

### The Ouroboros Life System / the chair (2021→2026)
15 route patterns (brochure, essay, zine (3,260-line component — the one
unruly editing surface), subsystems ×7, lineage ×6, precedents ×4, archive ×9
(noindex), concepts, refusal, the-system→redirect, colophon). Zero broken
links; everything reachable; every page has back-links. Issues: 2,445 lines
of orphaned components; 35 MB unused PNGs + stale public README; three
duplicate route-nav lists; duplicated page primitives across 6 files; OG
card missing; heading skips; dead buttons; OccupantGallery alt text; essay §IX
repeated nearly verbatim on /refusal.

Streamline: remove orphan chain + dead assets; single nav source; extract
shared primitives; split ZineSpread prose into data; OG card; a11y pass.
**Editing surface after: essay + slug-family records stand alone; zine prose
becomes one record file.**

### Patriotic Times (2025—2026)
66 routes, 63/63 plates complete and consistent (data ↔ files ↔ sitemap, zero
mismatches). Hub prose carries 35 curated chapter events (33 with plate deep
links). Issues: plates index = 53 MB eager; 26 plates >1 MB; ColoringCanvas
refs-in-render (CLS) + no keyboard + flood-fill memory spike on large plates;
"35 plates" metadata; unreachable placeholder branch; duplicated constants;
hub hero caption ("plate 34 is the image the book ends at") contradicts the
63-plate run.

Streamline: index lazy/optimized; **plate re-encode pass (the single biggest
weight win on the site)**; canvas fixes; metadata; constants; caption check
with Adnan. **Editing surface after: `_data.ts` + the CHAPTERS block — clean.**

### The Ouroboric Condition (2018)
One route, one atlas page, 17 specimens. Prose centralized in `data.ts`
(~4,700 words) — the cleanest editing seam on the site already. Issues:
canonical=C1; the repo's only lint error; `X0` dead; world size defined
twice; localStorage written but never restored; plate state not
shareable/bookmarkable; zoom disabled (deliberate); EB Garamond downloaded
again via Google fonts though self-hosted at root.

Streamline: C1; hash-state for specimens; Link fix + chart import; a11y on
plate nav; reuse root fonts. **Single page is the right shape — no split.**

### The Manufacture of the Subject (2015)
One route, one immersive descent. ~9,000 words of prose scattered across six
TSX files — **the weakest editorial surface of all works**. No social image
image emitted at all; canonical=C1; hover-only glossary; effect lint noise.
Streamline: copy extraction into one `copy.ts`; canonical + OG; `.term`
keyboard/touch; lint cleanup. **Editing surface after: `copy.ts`.**

### The Psychopolitics of Socialization (2026)
One static HTML page (124 KB) + data (362 KB / 108 KB gz, 620 nodes, clean
per-record seam) + dc-runtime. Issues: unpkg React (C2); no `lang`, no
canonical; Babel+eval machinery unused; og.png compressible.

Streamline: vendor React; head fixes; recompress. **Editing surface:
`atlas-data.js` records — already clean.**

### Thinkroom (tool, unlisted)
Gate works; cookie/noindex correct. Issues: not timing-safe compare; no rate
limit; deterministic cookie value; not covered by the disclosure page.
Streamline: harden (3 small changes); optionally Disallow in robots.
**Deliberately unlisted — keep it that way.**

### Shell
Landing/404/robots/sitemap/redirects/headers all mostly sound; issues are
C1–C7 above plus: 404 links 5 of 7 works; landing JSON-LD; OG strip year

## 3. The streamlining plan

Ordered by risk, not by size. Each phase lands with its verification command.

**Phase 0 — Truth pass (mechanical; no editorial judgment; nothing removed
that history can't restore).**
1. C1 canonical fixes (all 18) + remove root canonical default.
2. C4 sitemap chair routes (+24).
3. C5 stale counts: "Six live projects"→seven, "35 plates"→63, OG strip
   year span, title double-suffix (16), not-found work links.
4. C6: OG cards for ohcose/patriotic/chair/manufacture (one-liners on the
   existing helper); per-route `openGraph.url` sweep.
5. C8 lint zero-out including the three real bugs (hydration, Schematic,
   canvas refs).
6. C10 orphan removal: preview routes, OuroborosPortal chain, unused SVGs;
   unused chair PNGs moved to a dated attic outside the repo (not deleted —
   parked).
7. Docs to reality: README + llms.txt rewrite; stale comments; glossary
   flags; colophon branch line.
8. Verify: build + lint clean, spot-check prerendered canonicals, sitemap
   count. **Deliverable: a truthful, consistent site — "ready for editing"
   in the mechanical sense.**

**Phase 1 — Adnan's rulings (see §4).**
- v1/v2 canon decision and its mechanical follow-through.
- Instrumentation disclosure rewrite (draft in his voice, scanned, his gate).
- Thinkroom hardening (no ruling needed, listed here for phasing).

**Phase 2 — Per-work betterments (the big ranked items).**
- Patriotic: index lazy-load + image re-encode pass (**-40+ MB**), canvas
  keyboard + memory + CLS.
- Chair: orphan cleanup already in P0; then nav single-source, primitives,
  ZineSpread prose extraction, a11y.
- OHCOSE: manifest + LeafShell + Phase I migration (the largest refactor;
  big win: sync hazards gone, edit surface clean).
- Manufacture: `copy.ts` extraction.
- Closed-loop: slider labels, math-tooltip keyboard, apparatus polish.
- Ouroboric: hash state, a11y, fonts.
- Psychopolitics: vendored React, head fixes.
- Fonts/publics diet site-wide.

**Phase 3 — ArtCraft** (see §4, Q3): the apps are the toolbelt for the next
stage — image pipeline (PhotoCraft/LightCraft), new vector work
(VectorCraft), motion (EffectCraft/FilmCraft), decks (DeckCraft) — making
new things on the site.

**Standing instrument.** A live board for this workstream (one page, works ×
phase matrix, NEEDS-ADNAN section) so each session resumes without
re-auditing. Existing boards checked: none exists for this project.

## 4. What waits on Adnan

**Q1 — closed-loop v1/v2 canon.** One line: which surface is the record —
the v1 essays+plates, the v2 rebuild, or both presented as two doorways?
Recommendation: keep v2 as the primary presented surface; keep the **v1
essays** (the 5 MDX pieces + note) as first-class and indexed — they are
unique content — and treat the v1 dynamics/mathematics as a linked "first
version" archive (indexed only if you say so; noindex if not). Unlocks:
the C1/C3 fixes; kills the duplicate-index dilution. Cost of late: Google
decides for you, badly — 16 pages currently point their canonical at the
homepage, and both branches compete in the index meanwhile.

**Q2 — the disclosure page.** One line: approve a rewritten
`/closed-loop/instrumentation` (true at site level: thinkroom cookie,
the four storage keys by name, third-party fix note) drafted in your voice
for your gate? Unlocks: the site stops publishing a false privacy promise.
Cost of late: it's live now, and it's the kind of sentence that gets quoted.

**Q3 — ArtCraft first target.** One line: start ArtCraft by using PhotoCraft
on the 63 plates + chair images (the re-encode pass), or straight to making
something new (VectorCraft OG cards / a new visual work)? Recommendation:
PhotoCraft pass first — it pays for itself on every visit — then new work.
Cost of late: none for new work; every week the plates stay 53 MB is just
weight.

**Q4 — board + commits.** One line: create the live board (autostimulus
workstream) and commit Phase 0 as reviewed units? Recommendation: yes to
both; commits only when you say go.
